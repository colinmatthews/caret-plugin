# Caret

Caret turns answers into interactive visuals you can explore, right in the chat.
Ask your assistant what an agent just built, how a system or process works, why a
plan ranks things the way it does, or what a set of numbers says, and Caret draws
it: flows, architectures, timelines, charts and comparisons you can click through.

This plugin connects Claude or Codex to Caret's hosted MCP server
(`https://mcp.learnwithcaret.com/mcp`) and adds the `create-visual` skill, which
tells the assistant when a visual will help and how to build a good one, and the
`set-brand` skill for Enterprise accounts that bring their own design system.

## Install

- Claude Code: `/plugin marketplace add colinmatthews/caret-plugin`, then
  `/plugin install caret@caret`.
- Codex: `codex plugin add caret@caret` once the Caret marketplace is added.

The first time Caret runs, you sign in to your Caret account (free to start at
[learnwithcaret.com](https://learnwithcaret.com)).

## Privacy

Visuals are private to your account. See the
